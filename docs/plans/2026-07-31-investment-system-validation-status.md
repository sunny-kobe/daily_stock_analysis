# 个人投资决策系统验收状态与下一阶段主线

## 结论

截至 2026-07-31，当前实现可以用于研究、确定性回测、策略记录和模拟观察，但还不能据此投入真实资金。

- **研究与回测工具：可用，但历史成绩尚未建立。** 已能固定策略版本、从冻结 source JSON 构建资格清单、运行继续持有基线、记录人工阶段变更和复盘结果；synthetic fixture 已验证回测实现，真实数据库已完成候选导出，但合格样本仍为 0。
- **新决策复盘资料：账本和显式准备入口可用。** 新持仓建议会绑定 `portfolio-current-policy@1.0.0`，把决策时输入和来源证据保存为不可原地改写的快照；系统可逐持仓准备 benchmark、FX 和复权行情，缺产品、交易单位、风险、成本或研究上下文时明确显示“资料不足”，不进入有效策略成绩。
- **真实资金策略：未就绪。** 当前结果只证明系统链路基本可运行，不证明策略胜率、收益或风险调整表现已经提高。
- **交易边界：保持不变。** 系统没有订单、券商或自动交易入口，策略阶段和所有真实动作仍由人确认。
- **验收数据边界：安全。** 本轮数据库写入验证全部使用临时数据库，没有修改真实持仓数据库。

| --- | --- | --- |
| 查看持仓建议 | 可用 | 普通界面只显示“加仓、持有、减仓、清仓、资料不足”，不暴露内部双字段枚举 |

## 历史样本当前边界

历史样本流程固定为：**冻结原始数据 -> 候选记录 -> 可用样本 / 排除原因 -> 继续持有基线成绩**。source hash 保护冻结原始内容，dataset hash 保护资格清单和事件内容，样本集合 hash 保证比较使用同一批可用样本。

synthetic fixture 已验证构建和回测实现；当前数据库也已只读导出真实候选 source，但 101 条候选全部被资格构建器排除，因此仍没有真实历史成绩。`current_prospective` 研究快照只适用于当前前向决策，不得倒灌到历史样本、历史 benchmark、历史 FX 或历史产品身份。

## 已修复的阶段门槛

### `forward_only` 不再伪造合格历史回测

当前策略依赖当时的 AI、新闻和其他无法可靠恢复的输入，因此只能从今天开始积累模拟样本，不能伪造历史成绩。修复后：

- `historical_status=not_available` 的记录永远是 `qualifying=false`，API 也拒绝将其作为合格历史回测写入。
- 历史可重放策略仍必须先有 `historical_status=complete` 的合格回测，才能由人进入模拟观察。
- `forward_only` 策略从“待回测”由人填写理由后开始模拟观察；页面不会暗示它已完成历史回测，也不会自动晋级。

本项只修正阶段和记录语义，不证明任何策略收益、风险调整表现或真实资金资格。

## 已知限制

- 当前没有足够的合格历史样本，不能声称策略胜率、收益、最大回撤或相对基准表现已改善。
- 当前数据库已能导出真实候选，但 101 条候选都没有决策时绑定的策略版本、结构化输入 hash 和完整 source body；不能事后补算。
- 新证据账本只服务上线后的建议；旧 101 条继续显示资料不足并保持排除，不使用当前行情、registry 或研究材料回填。
- 已冻结质量上下文使用 `000001/SPX/HSI`，策略版本要求 `000300/SPY/HSI`；benchmark 身份冲突和 benchmark 行情缺失必须在新的前向记录中修正，旧记录保持排除。
- 旧 `stock_daily` 行可能没有明确复权身份或稳定来源版本，不能回填成合格证据；新准备的行情会保存明确复权口径，但现有候选仍未自然成熟到 5/20/60 个对齐交易 bar。
- 当前策略的 AI 和新闻输入只适合前向模拟；历史持有基线的成绩不能冒充当前策略成绩。
- 5/20/60 日结果需要真实时间成熟，未成熟样本不能提前计为成功或失败。
- 持仓页的实时行情可以返回，但后台板块和名称查询可能触发 Eastmoney 长重试。核心页面没有被阻塞，后续仍应收紧超时与取消行为。
- 本轮未使用真实持仓数据库做写入验收，因此没有验证真实数据库迁移或真实资金工作流；这正是当前安全边界。
- 建议、质量上下文和证据 sidecar 目前不是同一数据库事务；sidecar 失败会保留普通建议并标记“资料不足”，但不会伪装成已保存。后续若要改成单事务，需要单独评估共享写入边界。

3. **已完成：运行资格清单和继续持有基线。** 结果为 0 条可用样本、101 条排除，持有基线状态为“资料不足”，没有真实成绩。
4. **已完成：建立新决策证据账本。** 新建议绑定固定策略版本和结构化输入 hash；完整资料显示“已保存”，缺资料显示“资料不足”；旧记录不回填。
5. **下一步：运行第一次每日全持仓模拟。** 先用显式入口准备 `000300/HSI/SPY`、FX 和复权行情，再核对产品、交易单位、风险和成本证据；每条建议绑定冻结输入和人的决定，只记录，不投入资金。

8. **最后才考虑小额真实验证。** 只有历史样本和未来模拟都达到预先确定的标准，才由人决定是否进入有限资金周期。
