# 个人投资学习档案

版本：2026-08-17（Asia/Shanghai）

用途：作为仓库内长期投资学习、研究和复盘的个人基座，并可按需提供给 ChatGPT、Gemini 或其他 AI，作为一致的起始上下文。

配套文件：[个人投资当前上下文](个人投资当前上下文.md)和[个人投资学习记录](个人投资学习记录.md)。持仓事实源始终是 `data/stock_analysis.db` 中的 DSA 账本。

## 文档角色和隐私说明

- 本文是慢变化的个人学习基座，只维护目标、认知水平、证据规则和学习方法，不再手工维护易过期的持仓与行情。
- 当前持仓、缓存估值、风险政策和组合观察放在“个人投资当前上下文”，每次使用前通过 DSA 只读刷新。
- 学到了什么、纠正了什么和下一步是什么，只追加到“个人投资学习记录”，不回写历史判断。
- 本目录位于公开的个人 fork；本人已明确接受持仓、成本、现金和资产规模进入公开 Git 历史。删除当前文件不能自动清除历史副本。
- 上传第三方 AI 前，应确认接受其隐私、训练和数据保留政策。远程聊天不是事实源，也不是第二份权威学习账本。
- DSA 没登记的券商账户、加密资产、负债、收入、应急资金和未来支出均不能推定为零。

## 给 AI 的使用协议

请把本文内容分为四类处理：

1. **已确认事实**：以配套的“个人投资当前上下文”和 DSA 账本为准；本文不维护实时持仓。
2. **个人偏好**：长期投资、偏好行业 ETF 和主动研究、不喜欢把宽基设为强制主仓。
3. **暂定目标**：长期年化 30% 和 40% 回撤压力情景；它们可以调整，不能用来倒推杠杆或仓位。
4. **未知项**：实时价格、完整外部资产、负债与现金需求、SKHY 的精确产品身份、完整组合权重等。

同时读取本文和最新“个人投资当前上下文”。在第一次回复中：

- 先复述你理解的事实、偏好和关键未知项，指出任何冲突，不要立即给“强烈买入”或具体交易数量。
- 优先帮助我完成一个真实持仓问题，而不是给我一份很长的课程清单。
- 关键结论优先使用公司、交易所、基金公司、指数公司、监管机构等一手来源；AI 的说法、博主视频和多模型一致不算独立证据。
- 如果需要联网、实时行情或我未提供的个人财务信息，先说明它会改变什么结论，再询问我。
- 所有动作讨论必须把 `position_action`（现有仓位持有/减少/退出）与 `incremental_action`（新增资金分批加/等待/不加）分开。
- 不因成本价、单日涨跌、低市盈率、热门题材、既往盈利或 AI 自信度单独推导动作。

## 本地、GitHub 与远程 AI 的边界

- 仓库工作树中的三份文件是唯一可迁移记录；GitHub 用于版本历史和多设备同步，DSA 是组合事实源。
- ChatGPT Project 或 Gemini 只选择一个作为长期远程主工作区，另一个只用于必要的第二意见或反例检查。
- 远程主工作区上传本文和最新“个人投资当前上下文”；“个人投资学习记录”默认只提供与当前问题相关的条目。
- 一个真实问题使用一个独立聊天。远程聊天结束时生成一段“学习回写块”，经本人审核后追加到仓库学习记录。
- 不手工同步两套完整聊天或日志，不把远程记忆、AI 自信度或多模型一致当作证据。

## 我的情况

### 目标和约束

- 核心目标：长期资产增值，提高现有持仓和新增资金的决策质量，本质上希望赚钱。
- 投资期限：终身参与投资，但不等于终身持有某只行业 ETF、个股或复杂产品。
- 时间投入：每周可投入 8 小时以上，且对研究本身有兴趣。
- 回报愿望：长期年化 30%，只是可调整的进取愿望，不是承诺，也不作为放大杠杆和集中度的依据。
- 风险表述：40% 是压力测试情景，不是日常风险预算，也不表示跌到 40% 才处理风险。
- 资产背景：曾表示投资本金约占可投资净资产的 90%，目前没房没车。应急资金、负债、收入稳定性和未来 1 至 3 年大额支出仍未知。
- 风格偏好：对宽基核心兴趣较低，认为回报吸引力不足；更喜欢行业 ETF 和少量主动研究。宽基仍应作为机会成本和政策基准，而不是被强迫成为主仓。

### 经验和当前水平

我的实际接触范围包括股票、ETF、基金、QDII、杠杆 ETF 和加密资产，也有真实交易和盈利经历。更准确的水平定位是：**有市场参与经验的初级研究者，而不是完全新手；产品、财报、估值和组合研究尚未形成稳定体系。**

已经具备的认知：

- 知道公司业绩增长但股价下跌，可能是未达到市场预期，也可能与现金流、债务或其他质量问题有关。
- 看到利润增长而经营现金流持续下降时，会主动怀疑盈利质量、债务和经营方向。
- 对 AI 的“强烈买入”会担心假消息、情绪过热和来源污染，不会无条件相信。
- 能识别自己的追高、死扛亏损、缺少止损或 thesis 失效条件等行为问题。

当前主要短板：

- 还没有系统读过财报，三张表、营运资本、自由现金流、债务、稀释和会计质量需要从真实持仓开始学习。
- 把“远期市盈率更小”倾向理解为“更有潜力”，尚未充分区分盈利预测、周期性、风险、估值基准和价格隐含预期。
- 评价 ETF 时容易从过去三年跑赢和题材热度出发，尚未稳定检查指数规则、底层重合、费率、跟踪误差、估值、汇率、溢价和幸存者偏差。
- 当前常用“问 AI、凭经验、根据回撤调仓”，还没有统一的来源、基准、反方、失效条件和复盘闭环。
- 高频观看股市博主视频。视频适合作为线索来源，但容易带来追逐热点、选择性证据和过度交易。

## 最小可执行学习路线

不以看完多少书、视频或课程为目标。每周围绕一个真实持仓问题运行同一闭环：

`真实问题 -> 一手资料 -> 事实与推断分离 -> 计算复核 -> 最强反方 -> 组合影响 -> 冻结判断和基准 -> 到期复查`

这是一条按永久损失风险和知识前置依赖排列的默认路线，不是不可调整的课程目录。持仓、资金期限或主要未知项变化时，应重新判断当前最高 ROI 的关卡。AI 来源核验、最强反方、失效条件和行为约束从第 0 关开始贯穿全程，不是后置课程。

### 第一批项目

1. **第 0 关：个人资金约束与投资政策**：先确认应急资金、负债、未来 1 至 3 年支出、收入稳定性、DSA 外资产、主要计价币种和风险能力；区分愿意承受的波动与实际有能力承受的损失。信息不完整时不推导交易数量或新增仓位。
2. **复杂产品身份与风险**：查清 SKHY 的法律和交易身份，再对比 SKHY 与 HK07709 的底层、转换关系、币种、费用、流动性、每日重置和持有期风险。完成前，不把二者当作普通长期股票，也不因浮亏自动新增风险。
3. **组合重合 X-ray**：穿透 QQQM、513870、159819、512480、515880、562500 的指数规则、前十大成分和行业权重，找出相同公司和相同风险因子；用一个简单宽基作为事前政策基准。
4. **第一份公司财报练习**：优先从真实持仓中选一家相对容易追踪的公司，例如 GOOGL。先完成“收入 -> 营业利润 -> 经营现金流 -> 自由现金流 -> 净现金/净债务 -> 股本稀释”，暂不急着给目标价。
5. **再学习估值**：能解释现金流之后，再做相对估值、三情景敏感性和 reverse DCF，重点回答“当前价格隐含什么增长”，而不是寻找一个精确目标价。

### 各关通过标准

- 第 0 关：能用比例或区间说明流动性、负债、资金期限、风险能力和政策基准，关键未知项不会被当成零。
- 复杂产品：能依据一手文件解释产品持有什么、如何定价、费用、杠杆重置和两日路径依赖。
- 组合 X-ray：能识别最大的公司、行业、因子、币种和杠杆重复暴露，并说明新增标的会改变什么。
- 财报：能独立复算“净利润 -> 经营现金流 -> 自由现金流”，解释债务、营运资本和股本稀释。
- 估值：能给出价格隐含的增长与回报假设、三种情景和失效条件，而不是只给目标价。
- 前向验证：行动前冻结判断和基准，按 5/20/60 个交易日复查；短样本只验证流程纪律，不证明长期优势。

### AI 和视频的日常规则

- 普通视频只记录一句核心 claim 和它声称的原始来源；只有可能改变 thesis、估值或动作的 claim 才完整核验。
- 先写下自己的初始判断，再让 AI 给最强反方，避免 AI 替自己生成事后理由。
- AI 适合做原文提取、页码定位、计算复核、反方论证、证据缺口和复盘，不适合做最终买卖决定。
- 原理和旧教材可以继续用；公司数据、产品条款、ETF 成分与费率、监管规则、估值输入和市场事实必须按使用日期刷新。

### 判断自己是否进步

- 能否准确说明每个产品“到底持有什么、如何定价、风险从哪里来”。
- 能否在不看资料时解释三张表如何连接，并复算关键数字。
- 能否在行动前固定来源、基准、最强反方和 thesis 失效条件，而不是事后改写理由。
- 追高、无证据新增、死扛和按回撤冲动调仓的次数是否下降。
- 主动判断在费用、风险和相同基准口径下，经过足够长的前瞻样本后是否真正增加价值。20 个交易日只验证流程能否运行，不证明长期优势。

## 仍需本人补充的关键信息

- 可投资净资产是否已经扣除 6 至 12 个月应急资金。
- 未来 1 至 3 年是否有买房、买车、结婚、教育、医疗或其他大额支出。
- 是否有负债、保证金、借款投资或稳定性较低的收入来源。
- 个人财富的主要计价币种和总组合政策基准。
- DSA 之外是否还有股票、基金、加密资产或现金账户，以及是否希望纳入同一组合。
- 当前最想先研究的持仓问题是什么，而不只是“现在该不该买”。
