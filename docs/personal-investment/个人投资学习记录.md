# 个人投资学习记录

用途：只记录真正改变理解或后续研究方式的学习结果。本文追加新条目，不回写旧判断，不承担持仓账本、行情快照或交易记录职责。

配套文件：[个人投资学习档案](个人投资学习档案.md)和[个人投资当前上下文](个人投资当前上下文.md)。

## 使用规则

- 一个条目对应一个真实问题，不为完成数量而记录。
- 先写自己的初始判断，再记录一手证据和 AI 反方，避免事后合理化。
- 只有经本人核对的内容才能写入；远程 AI 聊天和自动摘要不是权威记录。
- 会影响动作的事实必须保留来源、报告期或发布日期、访问时间和适用截止时间。
- 交易动作和正式决策证据继续进入 DSA，不在本文建立平行账本。

## 2026-08-17：学习记录应该维护在哪里

**真实问题**

是否应该在本地、ChatGPT 网页版和 Gemini 中分别维护一套投资学习记录。

**我的初始判断**

本地和远程 AI 似乎都可以各维护一份，以便不同工具延续上下文。

**结论修正**

- 本地文件应是唯一可迁移、可审计的学习记录；DSA 继续作为组合事实源。
- ChatGPT Project 或 Gemini 只选一个作为长期远程主工作区，不手工维护第二份权威日志。
- 另一个模型只用于必要的第二意见、反例或来源交叉检查，多模型一致不增加证据权重。
- 远程聊天结束后，只生成一段经本人审核的回写条目并追加到本文。
- 基座、当前上下文和学习记录按变化频率拆开，避免持仓更新迫使整份个人档案不断重写。

**依据**

- OpenAI 官方 Projects 文档说明，项目可以让相关聊天共享文件、项目指令和来源；网页版项目不能直接访问本地文件夹，需要上传或连接来源：<https://learn.chatgpt.com/docs/projects>。
- DSA 已承担持仓、成本、现金、产品登记、风险政策和决策证据职责，学习记录不应重复这些事实。

**对投资动作的影响**

- `position_action`：无。本条目不形成持有、减少或退出建议。
- `incremental_action`：无。本条目不形成新增资金建议。

## 2026-08-17：将学习路线纳入 DSA 项目

**真实问题**

是否把个人投资档案和学习记录纳入公开的 DSA 个人 fork，用 GitHub 做版本历史和同步。

**我的初始判断**

公开持仓的边际隐私风险可以接受，因为 DSA 项目和历史提交已经包含相关持仓信息。

**结论修正**

- DSA 采用双主线：产品主线负责分析系统，学习主线负责基于真实持仓的问题驱动学习。
- 仓库工作树中的三份文件成为唯一可迁移学习记录；GitHub 只承担历史和同步，不替代 DSA 账本。
- 旧的单体学习档案和整理式聊天记录退出当前结构，避免与慢变量档案、快变量上下文和追加式学习记录重复。
- 本人明确授权公开持仓、成本、现金和资产规模；该授权不包括凭证、券商账号或其他人的信息。

**对投资动作的影响**

- `position_action`：无。本条目不形成持有、减少或退出建议。
- `incremental_action`：无。本条目不形成新增资金建议。
