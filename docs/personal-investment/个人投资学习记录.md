# 个人投资学习记录

用途：只记录真正改变理解或后续研究方式的学习结果。本文追加新条目，不回写旧判断，不承担持仓账本、行情快照或交易记录职责。

配套文件：[个人投资学习档案](个人投资学习档案.md)和[个人投资当前上下文](个人投资当前上下文.md)。

## 使用规则

- 一个条目对应一个真实问题，不为完成数量而记录。
- 先写自己的初始判断，再记录一手证据和 AI 反方，避免事后合理化。
- 只有经本人核对的内容才能写入；远程 AI 聊天和自动摘要不是权威记录。
- 会影响动作的事实必须保留来源、报告期或发布日期、访问时间和适用截止时间。
- 交易动作和正式决策证据继续进入 DSA，不在本文建立平行账本。

## 2026-08-17：学习顺序如何验证

**真实问题**

如何判断定制学习计划不是 AI 随意排列，学习顺序是否符合当前实际情况。

**我的初始判断**

现有顺序从复杂产品、组合 X-ray、财报到估值看起来合理，但无法仅凭 AI 的解释证明它正确。

**新增的一手证据**

- CFA Institute 2026 年组合规划材料把书面投资政策、风险能力与意愿、流动性、期限和约束视为组合管理起点：<https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/basics-of-portfolio-planning-and-construction>。
- Investor.gov 说明资产配置取决于投资期限、风险承受能力和个人财务状况：<https://www.investor.gov/introduction-investing/getting-started/asset-allocation>。
- SEC 与 FINRA 均说明多数杠杆和反向 ETF 每日重置，长期表现可能显著偏离标称倍数，因此复杂产品机制应优先于常规估值学习：<https://www.sec.gov/investor/pubs/leveragedetfs-alert.htm>、<https://www.finra.org/rules-guidance/key-topics/etf/non-traditional-etf-faq>。
- Damodaran 的估值框架以现金流、增长、再投资和风险为输入，支持先理解财报和现金流再做估值：<https://pages.stern.nyu.edu/~adamodar/pdfiles/country/valintroallSlovenia2019.pdf>。

**结论修正**

- 学习计划不能在事前被证明永远正确，只能通过风险优先级、知识依赖和每关可检查产出持续证伪与调整。
- 在复杂产品前增加“第 0 关：个人资金约束与投资政策”。约 90% 可投资净资产参与投资，而应急资金、负债、收入稳定性和未来支出仍未知，这些信息会改变后续所有风险判断。
- 默认顺序修正为：个人约束与投资政策 -> 复杂产品 -> 组合 X-ray -> 财报与现金流 -> 估值与隐含预期 -> 前向验证。
- AI 来源核验、最强反方、失效条件和行为约束应从第 0 关贯穿全程，而不是后置模块。
- 课程完成数量不是进步证据；能独立解释、复算、提前冻结判断并减少冲动行为才是阶段通过标准。

**对投资动作的影响**

- `position_action`：待复核。本条目不改变现有仓位动作；第 0 关和产品证据未完成前，不据此生成减仓或退出数量。
- `incremental_action`：WAIT。第 0 关未完成前，不用回报目标、浮亏或 AI 信心推导新增风险。
